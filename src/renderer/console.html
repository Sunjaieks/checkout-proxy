📋 Request Console
About Request Console

📋 Overview

  • Records HTTP/HTTPS requests and response that match rules defined in your profile
  • Displays the final request parameters after MITM proxy modifications
  • Requests without matching any rule are not recorded

💾 Data Persistence

Requests are preserved even when this window is closed!
When you reopen the Console, you will see all previously recorded requests.

📊 Limits

  • Maximum 1000 requests are stored (FIFO)
  • Oldest requests are removed when limit is reached
  • Click "Clear" to manually delete all records

🪄 Tips

  • Double-click the row to open a window of Entry Details
  • In the Entry Details window, double-click any position within the request/response body's header section for expending
Press Ctrl/Cmd+F to search, Press Ctrl/Cmd+D to clear
